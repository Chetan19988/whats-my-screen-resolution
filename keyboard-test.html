How to Test Your Keyboard

Run a quick visual check without installing software.

STEP 01

Focus the test area

Click inside the visual keyboard. The prompt disappears when the tester is focused and ready to receive your physical key presses.

STEP 02

Keyboard Test Limitations

Browser keyboard events cannot reveal every hardware or operating-system behavior.

Browser and system shortcuts

Some keys and combinations are reserved by the operating system or browser and may not reach this page. Function keys, media controls, firmware keys, and certain platform shortcuts can behave differently.

Keyboard layouts

The visual reference uses a common US QWERTY arrangement. Physical layouts vary by region and keyboard model. The event code identifies a physical-position key where supported; the displayed label is only a reference.

Not a hardware rollover certification

The simultaneous count reflects keydown events that the current browser delivered to this page. It cannot certify N-key rollover, switch condition, electrical matrix behavior, wireless reliability or a keyboard's internal scan rate.

Frequently Asked Questions

How do I test a key?

Focus the visual keyboard and press the physical key. A highlighted key means its browser keyboard event reached this page.

Can this test certify N-key rollover?

No. It shows the simultaneous key events reported to the page, but browser, operating-system and device behavior can affect the result.

Why do some keys not appear?

Some keys are intercepted by the system or browser, and function or special keys may not generate webpage events. Layouts also vary.

Does the test record what I type?

No. It displays key labels and event codes in the current page session. It does not read text entered elsewhere, save keystrokes or upload key data.

Can I test a laptop or external keyboard?

Yes. Focus the test area and press the built-in or connected keyboard keys you want to check.

Does it work with an on-screen keyboard?

It depends on the device and browser. Some virtual keyboards do not send the same physical keyboard events to webpages.
