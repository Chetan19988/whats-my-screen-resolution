Aspect Ratio Details

Width and height are derived from the diagonal and ratio. Wider ratios mean shorter height for same diagonal.

What Is Screen Size?

Screen size refers to the diagonal measurement of the visible display area in inches. This is the standard way TVs, monitors, and laptops are sized. It is NOT the width or height directly.

The diagonal determines physical footprint. A 27-inch 16:9 monitor is about 23.5 wide and 13.2 tall. A 27-inch ultrawide 21:9 is about 23.5 wide but only 10.6 tall, spanning more horizontal space.

How to Calculate Screen Size

Use the Pythagorean theorem. For a diagonal d and aspect ratio a:b:

width = d * a / sqrt(a^2 + b^2)
height = d * b / sqrt(a^2 + b^2)

Example: 24-inch 16:9

sqrt(16^2+9^2)=18.358. Width = 24*16/18.358 = 20.9 in. Height = 24*9/18.358 = 11.8 in. In cm: 53.1 x 29.9.

PPI vs Screen Size

PPI uses screen size in the denominator. For a fixed resolution, larger physical screens have lower PPI. Check our PPI calculator for density, and our screen resolution checker for pixel dimensions.

Frequently Asked Questions

How do I measure my screen size?

Measure diagonally from one corner of the visible area to the opposite corner. Do not include bezels. Most manufacturers list the size in inches.

What does screen size mean exactly?

It is the diagonal length of the viewable display area, measured in inches. A 24-inch monitor means the diagonal of the visible screen is 24 inches.

Is screen size the same as resolution?

No. Screen size is physical inches. Resolution is pixel count. A 24-inch 1080p monitor has 92 PPI. A 24-inch 4K monitor has 184 PPI.

What is the most common screen size?

For desktop monitors: 24 and 27 inches. For laptops: 15.6 inches. For TVs: 55 inches. For phones: 6.1 to 6.7 inches.

How do I convert inches to cm?

Multiply inches by 2.54. For example, 24 inches = 60.96 cm. Our calculator does this automatically.

Can I calculate screen size without a ruler?

Yes. If you know the resolution and pixel pitch, you can derive size. Or if you know the diagonal from the manufacturer spec, just enter it above.
