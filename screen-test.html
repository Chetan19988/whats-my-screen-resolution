Drag with one finger or pointer to check for breaks and delayed movement. Then place two or more fingers on the canvas to check multi-touch response.

Swipe slowly across every corner and edge. A missing stroke, sudden jump or area that never responds may indicate a touch issue worth checking on the device itself.

What You Can Check

A practical visual inspection workflow for common display concerns.

Bright, dark or stuck pixels

Full-screen solid colors make small bright, dark or fixed-color pixels easier to spot. Check several colors before deciding a spot is a defect.

Backlight bleed and uniformity

Use pure black in a dark room and compare the corners, edges and center. IPS glow can shift with viewing angle, while bleed stays in a fixed position.

Color cast and grayscale

Neutral gray makes warm, cool or green tint easier to notice. Use grayscale and white patterns to compare channel balance visually.

Text sharpness and blur

High-contrast text and fine lines help reveal scaling, motion blur, ghosting or an incorrect display mode. They are visual clues, not measurements.

How to Get Started

Follow these steps for a reliable visual inspection.

1. Prepare the display

Let the screen warm up for at least 15 minutes. Use the native resolution, a standard color mode and a comfortable brightness level.

2. Enter fullscreen

Click the test area or press F. On desktop, browser fullscreen removes the address bar and taskbar from the test surface.

3. Inspect the whole screen

Check the center, edges and corners. Move to your normal viewing distance and compare the same area against more than one test color.

Understanding Screen Information

The browser can report useful environment values, but some display properties remain unavailable.

Viewport

The viewport is the CSS pixel area available to the browser. It can be smaller than the physical display because of browser chrome, scaling or window size.

Device Pixel Ratio

DPR describes how many physical screen pixels correspond to one CSS pixel. A higher DPR can make text and graphics appear sharper.

Frame estimate

The frame estimate observes this page's animation rate. It is not a certified monitor refresh-rate measurement and can change when the tab is inactive.

Physical display data

Native resolution, panel type, measured brightness and color gamut are hardware or system properties that ordinary browser JavaScript cannot reliably report.

Example: A phone may have a physical pixel grid much larger than its browser viewport because the operating system applies scaling. Always distinguish physical pixels from CSS pixels.

Frequently Asked Questions

Q.What is an online screen test?

It displays fullscreen patterns in your browser so you can visually inspect a display for pixels, uneven brightness, color cast, blur or touch issues.

Q.Do I need to install software?

No. The test runs in a modern browser and requires no download, account or installation.

Q.Can I use it on a phone or tablet?

Yes. Use fullscreen when available and use the touch area for response checks on touch-enabled devices.

Q.Does the browser know my physical resolution?

Not reliably. The browser reports the viewport and pixel ratio, but not the panel's physical pixel grid or hardware specifications.

Q.Why use fullscreen for a screen test?

Fullscreen removes browser and operating-system chrome so the complete test surface can be inspected.

Q.Is this a professional inspection?

No. Results are for reference only and can be affected by lighting, viewing angle, browser rendering and display settings.
