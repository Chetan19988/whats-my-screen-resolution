How to check input

Start the microphone, speak at your normal distance, and watch the meter move. If the bar barely responds, check the selected input and operating-system input level.

The reading is a relative browser signal level, not calibrated decibels, sound pressure or a microphone quality score.
Audio is analyzed locally in this page. No recording is made, and microphone data is not uploaded.

How to Test Mic Volume

STEP 01

Start input access

Press Start Microphone and allow access in the browser prompt. Access is not requested before this action.

STEP 02

Speak at a steady level

Talk normally toward the microphone and observe the live and peak indicators.

STEP 03

Check your input settings

Try another available microphone and review system input gain if the signal looks unusually low.

i

Measurement and Privacy Notes

The meter reports relative signal amplitude from browser audio analysis. It does not measure calibrated microphone loudness, noise floor, frequency response, or recording quality. Browser, device processing and environment affect readings.

Microphone access requires a secure context in modern browsers, usually HTTPS or localhost. Use the browser's site permission controls to manage access.

Frequently Asked Questions

Is this a decibel meter?

No. It shows relative signal activity, not calibrated dB or sound pressure.

When is permission requested?

Only after Start Microphone is pressed. Stop Microphone releases the audio track.

Is audio uploaded or recorded?

No. This mic volume page analyzes input locally and does not make a recording or upload audio.

Why can't I select a device?

Device labels may be hidden before permission or when the browser exposes only one input. Connect the microphone and check browser settings.
