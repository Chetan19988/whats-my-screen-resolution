How Device Information Is Detected

Values come from standard browser APIs and may vary across platforms.

Browser and platform identification

The browser name is estimated from browser-provided user-agent data. Operating system and platform labels are best-effort readings from the browser platform and user-agent fields; browsers may reduce, change or mask those strings.

Screen and viewport

Screen size describes browser-reported screen dimensions in CSS pixels. The viewport is the visible page area and can be smaller because the browser window, interface or operating-system scaling takes space.

Capabilities, not full hardware inventory

Logical CPU cores, approximate device memory, touch points, WebGL availability and connection details appear only when supported and exposed. This page does not identify an exact device model, inspect installed apps, or certify hardware specifications.

What the Browser Cannot Reliably Identify

Device information is intentionally limited for privacy, security and compatibility.

Not an exact hardware inventory

Web pages generally cannot reliably retrieve the exact computer or phone model, serial number, installed applications, full hardware configuration, or all system settings. Some values may be rounded or intentionally reduced.

Not a hardware certification

Reported resolution, memory, CPU core count, browser version and connection type are informational values from the current environment. They are not laboratory measurements, performance scores or warranty evidence.

Frequently Asked Questions

Can this tool identify my exact device model?

Usually not. Browsers limit device identification. This page shows only details exposed through browser APIs and does not claim an exact hardware model.

Is screen size the same as viewport size?

No. Screen dimensions refer to browser-exposed display dimensions in CSS pixels. The viewport is the page's current content area inside the browser.

Does it upload my device details?

No. Details are read locally from browser APIs and are not sent to a server by this tool.

Is the refresh rate shown here a hardware measurement?

No. Browsers do not generally expose a reliable physical display refresh rate. Page animation timing is only a rendering estimate and is affected by scheduling.

Why are some values unavailable?

Browser support varies, and some details are limited for privacy. Unsupported or masked information is shown as unavailable instead of being inferred.

Can I use this on a phone or tablet?

Yes. It reports browser-exposed values for phones, tablets, laptops and desktop systems, with the same privacy limitations.
